# Симулятор кейсов для Telegram

Виртуальная валюта, без пополнения и вывода.

## Запуск
1. Создай бота у @BotFather командой /newbot и скопируй токен.
2. Установи Python 3.10+ и зависимости:
   pip install -r requirements.txt
3. Задай токен и запусти.
   Windows (cmd):  set BOT_TOKEN=ТВОЙ_ТОКЕН  и затем  python bot.py
   Linux/Mac:      BOT_TOKEN=ТВОЙ_ТОКЕН python bot.py

## Что умеет
- Кейсы с реальными шансами редкостей, показ шансов перед открытием
- Инвентарь с постраничным просмотром, продажа предмета и продажа всего дешёвого
- Ежедневный бонус 500 монет
- Топ-10 по богатству

## Как менять
- cases.py: добавляй кейсы и предметы (у каждой редкости нужен хотя бы один предмет)
- bot.py: START_BALANCE, DAILY_BONUS, PAGE_SIZE вверху файла
